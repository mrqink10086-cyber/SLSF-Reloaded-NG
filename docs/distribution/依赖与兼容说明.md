# 依赖与兼容说明

## 必需依赖

| 组件 | 要求或用途 |
|---|---|
| Skyrim Special Edition | 1.6.1170，Windows x64 |
| SKSE | 2.2.6，与游戏版本匹配 |
| Address Library for SKSE Plugins | 安装对应游戏运行时的版本 |
| SKSE Menu Framework | 提供设置菜单；中文字体配置见安装说明 |
| SkyUI | 提供保留脚本的 `SKI_ConfigBase` 父类型；本模组使用 SKSE 设置菜单 |
| SexLab P+ | 场景与角色事实来源 |
| PapyrusUtil | 提供 StorageUtil 兼容接口 |
| Devious Devices NG | 提供 v2 API |
| Microsoft Visual C++ x64 运行库 | 与 VS 2022 工具链对应的运行库 |

上述依赖单独安装。本包只提供 SLSF 自有 DLL 和脚本。

## 可选集成

- 外观与纹身：RaceMenu/NiOverride、JContainers、SlaveTats。
- 玩法状态：Fill Her Up、Public Whore、SLACS、受支持的怀孕模组、Advanced Nudity Detection、SLSF Fame Comments、Bimbos of Skyrim。

安装可选模组时，同时满足该模组自身的依赖。外部事实暂时未知时，依赖该事实的新计分等待有效结果。

Public Whore 的编译接口声明依据冻结的 SLSF 调用点整理，本机缺少原始源码；具体安装版本的运行时接口需要在游戏联测中确认。

## 随包资产与许可

原有 `SLSF Reloaded.esp` 和 `Interface` 文件沿用本地原版资产，记录保持原样。
CommonLibSSE-NG 静态链接到 NG DLL；具体子模块修订见 `文件清单.json`。

`许可证` 目录保留项目 GPL-3.0、模板例外、原始署名及 CommonLib 的许可原文；中文来源说明见[鸣谢与来源](鸣谢与来源.md)。法律文本和原始署名保留原文件名与原文。
