# 鸣谢与来源

SLSF Reloaded NG 0.1 基于 [CommonLibSSE-NG Plugin Template](https://github.com/libxse/commonlibsse-ng-template) 初始化。该模板由 libxse 组织维护，模板 Git 历史记录的作者／贡献者包括 Qudix。

项目保留模板的 GPL-3.0 `LICENSE`、`EXCEPTIONS` 和原始 `ATTRIBUTION.md`，位于同目录的 `许可证` 文件夹。

CommonLibSSE-NG 是独立版本管理的依赖。包内同时保留其 `LICENSE`、`COPYING`；固定的源码修订记录在 `文件清单.json` 中。

`SLSF Reloaded.esp` 和 `Interface` 资源来自本地原版 SLSF Reloaded 资产目录，作者归属沿用原项目。其他模组源码用于只读接口参考；外部模组的运行依赖由使用者单独安装。

各组件的许可条款以 `许可证` 中的原文为准。
