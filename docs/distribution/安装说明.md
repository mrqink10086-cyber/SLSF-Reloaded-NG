# SLSF 声望重制 NG 0.1.4 中文测试版

适用环境：Windows x64、Skyrim Special Edition 1.6.1170、SKSE 2.2.6。
安装前请阅读同目录的[依赖与兼容说明](依赖与兼容说明.md)。

## 使用 MO2 安装

1. 在 MO2 中选择“从压缩包安装模组”，打开 `SLSF声望重制NG-0.1.4-中文测试版-MO2.zip`。
2. 使用名称“SLSF 声望重制 NG”安装。压缩包根目录就是游戏的 Data 内容，包含 ESP、`Scripts`、`SKSE`、`Interface` 等，无需再选择内层 Data 文件夹。
3. 在左侧勾选本模组，让它覆盖旧版 SLSF 的同名脚本；停用此前独立安装的 NG DLL 版本。
4. 在右侧插件列表勾选 `SLSF Reloaded.esp`。
5. 从 MO2 启动 SKSE，在 SKSE Menu Framework 中打开“SLSF 声望重制/设置”。全部设置及 JSON 操作在同页分组展开，点击“应用并保存”或关闭菜单保存修改。

安装后的模组目录结构如下。ESP、DLL、PSC 和 PEX 保留原名，以维持记录及脚本兼容。

```text
SLSF Reloaded.esp
Interface/
Scripts/                         25 个 PEX
Source/Scripts/                  对应的 25 个 PSC
SKSE/Plugins/SLSFReloadedNG.dll
SKSE/Plugins/SLSFReloadedNG.json
Docs/SLSFReloadedNG/              中文说明、文件清单、校验值和许可证
```

## 更新并保留设置

更新前，将正在使用的 `SKSE/Plugins/SLSFReloadedNG.json` 备份到单独的 MO2 配置模组，保持相同相对路径，并让配置模组在左侧具有更高覆盖优先级。本包内 JSON 是默认配置；MO2 的覆盖和替换安装会按其文件规则处理，不会运行本包的手动安装脚本。

导出文件及其他用户数据继续保留在原位置。首次安装直接使用随包默认配置。

设置跨存档共用，保存在 `SKSE/Plugins/SLSFReloadedNG.json`；声望数值仍随各自存档保存。“关系、时间与平衡”分组可分别设置朋友、恋人对 25 类声望的传播限制，泄密概率与高声望规则仍然生效。

“实时声望”分组自动显示当前存档中各地区的 25 类声望，可跟随玩家地区或手动选区。“声望增长倍率与传播限制”里的 `1.00` 是增长倍率，不是当前声望值；“应用并保存”保存配置，不直接设置声望。

在“声望操作”中选择地区和类别后点击“设置声望”，结果会显示实际回读数值，并在下一个游戏线程任务刷新兼容输出。供对话读取的 Global 对应玩家当前地区；设置其他地区时，进入该地区后才使用那里的数值。精液容器、不忠、戴绿帽和空脑在内置来源及外部启用都缺失时，仍按原周期规则清理一次。评论还有匿名、许可和概率条件，数值写入不代表立即出现某句对话。

本次修复按玩家与具体伙伴的 P+ 交互判断“喜欢男性／女性”，不再根据同场人数推断。请同时更新包内 DLL 与 `Scripts/SLSF_Reloaded_PPlusProbe.pex`；已有声望数值保持原值。

## 中文字体

在菜单框架的字体设置中启用 Chinese，选择 `Futura Condensed (CN)`。
也可在启动游戏前编辑 MO2 中实际生效的 `SKSE/Plugins/SKSEMenuFramework.ini`：

```ini
[Fonts]
PrimaryFont = Futura Condensed (CN)
EnableChinese = true
```

中文显示需要游戏的中文字体资源。出现方框时，检查上述选项和字体资源。字体设置沿用已安装菜单框架的配置。

## 手动安装

使用 MO2 时按上面的步骤安装即可。直接安装到游戏 Data 时，在解压后的包根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Docs\SLSFReloadedNG\手动安装.ps1 -DataDirectory 'E:\Games\Skyrim Special Edition\Data'
```

脚本先校验全部载荷哈希，再复制游戏文件，并保留目标中已有的 `SKSE/Plugins/SLSFReloadedNG.json`。请勿把外层解压文件夹再复制进 Data。

## 测试与文件校验

本包包含原有 ESP/界面资产、NG DLL、25 对 PSC/PEX、默认配置和许可文件。必要依赖另行安装；编译用外部接口声明留在源码仓库中。

游戏测试重点：保存与重载、地区切换、场景开始／前戏结束／阶段变化／结束、可选模组状态变化、JSON 重载及兼容 ModEvent 回应。自动核心、ASan、模糊和受控边界验证记录见源码仓库的交付报告；实际游戏联测由使用者执行。

`文件清单.json` 记录源码提交、CommonLib 修订、构建环境、脚本编译输入和各载荷的 SHA-256；`SHA256校验.txt` 列出相同校验值。两份清单不包含自身。重新构建可能改变 PE/PEX 时间戳，按清单识别具体交付文件。

## 从源码重新打包

准备仓库固定的 CommonLib 子模块和 MSVC/xmake 环境后，在源码仓库根目录执行：

```powershell
xmake build -y SLSFReloadedNG SLSFConfigProbe
powershell -NoProfile -ExecutionPolicy Bypass -File tools/compile-papyrus.ps1 -Clean
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-staging.ps1
```
