## 生产边界

`src/boundary/AppearanceProviders.cpp` 向 skee 交换接口，转发 SlaveTatsNG 的 v1 地址表，并在 JC 根广播结束后通过反射绑定 JArray/JMap/JValue。核心仍不依赖 CommonLib/SKSE。SlaveTats batch 使用 Actor* 及 Body/Face/Hands/Feet 参数序，false 为成功。

JC `getStr`、`getInt` 与 `retain` 使用真实 `RE::BSFixedString` 值参数/返回签名。结果 token 对应持有的 fixed string，Collect 完成复制后释放暂存；新数组 retain/release 配对。进程级绑定跨会话保留，快照按 epoch 更新。

`CollectRaceMenu()` 与 `CollectSlaveTats(Actor)` 在 `SLSF_Reloaded_ProbeNative.psc` 声明并注册；返回 SLSFRM1/SLSFST1 v1 字符串。现有 task 机制在排队及执行前检查含 BusinessOpen 的 epoch，Actor 跨任务以 VM handle 固定后重新解析。Actor 无效时返回 Unknown；取消或恢复旧查询仍返回类型匹配空值。调用方不得从空值或非 Ready 结果推断已知无数据。

这些端口要求游戏线程串行调用，BSFixedString 暂存不支持任意并发访问。沿用 SLCQ 保存旧 stack ID/返回类型，并以空值结束恢复的旧查询。B03 泵、C02 VM 宿主和下游计分仍待装配；实际宿主线程、ABI 与存读档行为仍待运行验证。
