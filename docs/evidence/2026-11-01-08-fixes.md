## 采集合同

`Scripts/Source/SLSF_Reloaded_PPlusProbe.psc` 按明确 thread ID 获取线程，检查状态、参与者、scene/stage，并在采样结束再次校验。epoch 用字符串传输，避免 Papyrus 32 位整数截断。收集 scene tags/annotations、stage tags、每角色角色字段和逐方向碰撞事实。28 位中没有公开可靠查询的 0/8/21 位保留 Unknown；physics 未注册时交互全未知。公开碰撞查询是逐次观察，无法保证跨角色整体原子性，不能把缓存数组的全 false 宣称为当前无交互。

角色行兼容原来的 8 字段，新增可选 roleUnknown 和 sexCode 字段。sexCode 保留 P+ 的 0–4；只有 0/1 贡献男女计数，玩家 female 为 1/4，未知性别不变成男性。旧帧没有 sexCode 时沿用原有布尔映射。P+ victim 与 SLSF Submissive 是不同概念：保留原始角色 DTO，但不添加 observed 角色覆盖。male/non-victim 回归显式切换 SubmissiveDefault，验证旧配置继续生效。

`SLSF_Reloaded_DDProbe.CollectScene` 由 DLL 注册为 latent native。DataLoaded 后取得并校验 v2 API、固定 DLL；`GetWornDevices` 和 `GetBondageState` 排入 SKSE task，复制为自有 wire。18 个设备位按关键词匹配；bondage 范围小于 0x200。成功的空设备列表才表示无设备。接口声明保留上游虚表顺序，许可证和改动说明保存在 `licenses/`。

`Scripts/Source/SLSF_Reloaded_ExternalProbe.psc` 查询 Public Whore tracker、FillHerUp inflation、FM/HP factions、EC/ES membership 及 FameComments/Bimbos presence；保留 FM/HP 原始 rank，兼容原来的 `>30`/`>1` 布尔结果，供下游保留分层计分。安装但记录/接口失效时模块为 Unknown，不能直接消费该模块的角色布尔默认值。响应包含全部八项模块状态。

共同原生 Identity/RequestActors/ActorRace 查询和 DDNG 采集通过 SKSE task 投递；排队前、执行前检查业务开放及 epoch。Identity/ActorRace 不把 raw engine pointer 留在闭包中，改为固定 VM handle 后在任务内解析。纯转义、hex、请求解析函数不访问引擎。

挂起查询以独立 SLCQ v1 记录保存，最多 4096 项，包含 stack ID 与 string/Actor[] 返回类型。codec 拒绝坏长度、未知类型和重复 stack，并保证解码失败不提交。载入成功后向保存的 stack 返回空字符串或空 Actor 数组，让脚本转 Unknown/失败重试；不恢复查询 payload、不重放旧引擎操作。保存先写 SLCQ，返回失败则停止写主记录。锁定 SKSE 的写接口本身总返回 true，I/O 异常由宿主回调边界截断；这不提供任意损坏 co-save 的恢复保证。
